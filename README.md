# Модальное окно (статичное)

Учебный проект по CSS-стилизации модального окна.

## Технологии
- HTML5
- CSS3
- Flexbox

## Особенности
- Фиксированное модальное окно
- Центрирование с помощью Flexbox
- Полупрозрачный фон (backdrop)
- Управление слоями через z-index
- Адаптация под мобильные экраны
- Скругления и тени
